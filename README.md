# VibeCheck

Upload a photo, an AI model running **in your browser** reads its mood, and VibeCheck
recommends songs that match.

Live site: https://danfdt.github.io/VibeCheck/

Final project for 웹프로그래밍 (Web Programming). HTML / CSS / JavaScript. The mood model is SigLIP running client-side through
Transformers.js, so photos never leave the device.

## Pages

| Page | What it does |
|------|--------------|
| `index.html` | Start screen and photo upload |
| `result.html` | Mood result, song recommendations, share card |
| `diary.html` | Soundtrack diary calendar and monthly summary |
| `about.html` | How it works |
